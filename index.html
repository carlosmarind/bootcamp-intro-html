1. Qué es HTML

HTML es un lenguaje de marcado que nos permite escribir contenido que el navegador interpreta y muestra en pantalla.

HTML no se usa para decorar la información, sino para estructurarla. Tampoco es un lenguaje de programación; para agregar comportamiento podemos usar JavaScript. Este lenguaje lo usaremos para organizar textos, mostrar enlaces, imágenes, tablas, formularios, etc.

Idea importante

Una etiqueta describe una parte del contenido. Por ejemplo, <p> representa un párrafo y <h1> representa el título principal de la página.

2. Estructura de una página HTML

Una página HTML normalmente tiene estas partes:

<!doctype html>
Le indica al navegador que el documento usa HTML moderno, si no lo colocamos, el navegador entra en modo de compatibilidad e interpretará nuestro HTML como si fuera una versión antigua.
<html>
Contiene toda la página. Aquí usamos lang="es" para indicar que usaremos el idioma español.
<head>
Contiene información para el navegador, como el título de la pestaña por ejemplo.
<body>
Contiene lo que las personas ven dentro de la página.

Ejemplo escrito como texto

                    
                        <!doctype html>
                            <html lang="es">
                            <head>
                                <meta charset="utf-8">
                                <title>Mi primera página</title>
                            </head>
                            <body>
                                <h1>Hola mundo</h1>
                                <p>Esta es mi primera página.</p>
                            </body>
                            </html>

3. Textos y títulos

Los títulos ayudan a ordenar la información. <h1> es el más importante. Después vienen <h2>, <h3> y así hasta <h6>.

Ejemplo de jerarquía de títulos

  • <h1>: título principal de la página.
  • <h2>: título de una sección.
  • <h3>: título de una subsección.

La etiqueta <p> crea un párrafo.

Podemos marcar una palabra como importante con <strong> o dar énfasis con <em>.

La etiqueta <br> hace un salto de línea.

4. Atributos HTML

Un atributo agrega información o modifica el comportamiento de una etiqueta. Se escribe dentro de la etiqueta de apertura, normalmente con la forma nombre="valor".

Por ejemplo, en <p id="presentacion" class="destacado">, id y class son atributos de la etiqueta <p>.

Atributos básicos

id
Identifica un elemento de manera única dentro de la página. También permite crear enlaces internos, como href="#inicio".
class
Agrupa elementos relacionados. Varios elementos pueden compartir la misma clase y un elemento puede tener más de una, separadas por espacios.
name
Identifica el dato de un campo cuando se envía un formulario. Se usa en elementos como <input>, <select> y <textarea>.

Atributos usados en formularios

  • type define el tipo de un <input>, por ejemplo, text, email, checkbox o radio.
  • value establece el valor de un campo o de una opción.
  • placeholder muestra una pista breve dentro de un campo vacío.
  • required indica que el campo debe completarse antes de enviar el formulario.
  • readonly permite leer el valor, pero impide modificarlo.
  • disabled deshabilita un control. Un control está habilitado cuando no tiene disabled; no existe un atributo HTML llamado enabled.
  • checked marca inicialmente un checkbox o un radio.
  • selected elige inicialmente una <option> dentro de un <select>.

required, readonly, disabled, checked y selected son atributos booleanos: su presencia activa la característica.

Ejemplo

<label for="correo-ejemplo">Correo:</label>
<input id="correo-ejemplo" name="correo" type="email" required>

<select id="curso" name="curso">
    <option value="html" selected>HTML</option>
    <option value="css" disabled>CSS (próximamente)</option>
</select>

6. Imágenes

La etiqueta <img> muestra una imagen. Normalmente se usa src para indicar la ruta de la imagen y alt para describirla.

9. Formularios

Los formularios se usan para pedir datos al usuario. Son de entrada, y se puede hacer varias cosas con ellos, como por ejemplo validarlos.

Agrupar campos con fieldset

La etiqueta <fieldset> agrupa campos que están relacionados dentro de un formulario. Por ejemplo, permite reunir varios botones de radio que responden a una misma pregunta.

Dentro de <fieldset> se usa <legend> para escribir el título o la pregunta del grupo. Esta estructura ayuda a entender el formulario y permite que los lectores de pantalla relacionen los controles correctamente.

Modalidad preferida:

Atributos del formulario

  • for conecta un <label> con un campo por su id.
  • name da nombre al dato que se enviaría.
  • type define el tipo de input.
  • placeholder muestra una pista dentro del campo.
  • value define un valor inicial o el valor de una opción.
  • Los botones de radio forman un grupo cuando comparten el mismo name.
  • checked marca la opción seleccionada inicialmente.

10. HTML semántico

HTML semántico significa elegir etiquetas por su significado, no por cómo se ven. Esto ayuda a lectores de pantalla, buscadores y otras personas que leen el código.

Etiquetas semánticas usadas en esta página

  • <header>: encabezado de una página o sección.
  • <nav>: navegación o menú de enlaces.
  • <main>: contenido principal.
  • <section>: bloque temático.
  • <article>: contenido que puede entenderse por sí mismo.
  • <aside>: información complementaria.
  • <footer>: cierre de una página o sección.

Nota para recordar

Si una etiqueta describe bien el propósito del contenido, probablemente es una buena elección.
