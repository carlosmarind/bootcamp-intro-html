Bloque HTML

En este bloque aprenderás a organizar el contenido de una página mediante etiquetas y atributos.

1. Qué es HTML

HTML es un lenguaje de marcado que nos permite escribir contenido que el navegador interpreta y muestra en pantalla.

HTML no se usa para decorar la información, sino para estructurarla. Tampoco es un lenguaje de programación; para agregar comportamiento podemos usar JavaScript. Este lenguaje lo usaremos para organizar textos, mostrar enlaces, imágenes, tablas, formularios, etc.

Idea importante

Una etiqueta describe una parte del contenido. Por ejemplo, <p> representa un párrafo y <h1> representa el título principal de la página.

2. Estructura de una página HTML

Una página HTML normalmente tiene estas partes:

<!doctype html>
Le indica al navegador que el documento usa HTML moderno. Si no lo colocamos, el navegador entra en modo de compatibilidad e interpretará nuestro HTML como si fuera una versión antigua.
<html>
Contiene toda la página. Aquí usamos lang="es" para indicar que usaremos el idioma español.
<head>
Contiene información para el navegador como, por ejemplo, el título de la pestaña.
<body>
Contiene lo que las personas ven dentro de la página.

Ejemplo escrito como texto

<!doctype html>
<html lang="es">
    <head>
        <meta charset="utf-8">
        <title>Mi primera página</title>
    </head>
    <body>
        <h1>Hola mundo</h1>
        <p>Esta es mi primera página.</p>
    </body>
</html>

3. Textos y títulos

Los títulos ayudan a ordenar la información. <h1> es el más importante. Después vienen <h2>, <h3> y así hasta <h6>.

Ejemplo de jerarquía de títulos

  • <h1>: título principal de la página.
  • <h2>: título de una sección.
  • <h3>: título de una subsección.

La etiqueta <p> crea un párrafo.

Podemos marcar una palabra como importante con <strong> o dar énfasis con <em>.

La etiqueta <br> hace un salto de línea.
Esta línea aparece debajo de la anterior.

HTML da estructura al contenido que muestra el navegador.

4. Atributos HTML

Un atributo agrega información o modifica el comportamiento de una etiqueta. Se escribe dentro de la etiqueta de apertura, normalmente con la forma nombre="valor".

Por ejemplo, en <p id="presentacion" class="destacado">, id y class son atributos de la etiqueta <p>.

Atributos básicos

id
Identifica un elemento de manera única dentro de la página. También permite crear enlaces internos, como href="#inicio".
class
Agrupa elementos relacionados. Varios elementos pueden compartir la misma clase y un elemento puede tener más de una, separadas por espacios.
name
Identifica el dato de un campo cuando se envía un formulario. Se usa en elementos como <input>, <select> y <textarea>.

Atributos usados en formularios

  • type define el tipo de un <input>, por ejemplo, text, email, checkbox o radio.
  • value establece el valor de un campo o de una opción.
  • placeholder muestra una pista breve dentro de un campo vacío.
  • required indica que el campo debe completarse antes de enviar el formulario.
  • readonly permite leer el valor, pero impide modificarlo.
  • disabled deshabilita un control. Un control está habilitado cuando no tiene disabled; no existe un atributo HTML llamado enabled.
  • checked marca inicialmente un checkbox o un radio.
  • selected elige inicialmente una <option> dentro de un <select>.

required, readonly, disabled, checked y selected son atributos booleanos: su presencia activa la característica.

Ejemplo

<label for="correo-ejemplo">Correo:</label>
<input id="correo-ejemplo" name="correo" type="email" required>

<select id="curso" name="curso">
    <option value="html" selected>HTML</option>
    <option value="css" disabled>CSS (próximamente)</option>
</select>

9. Formularios

Los formularios se usan para solicitar datos al usuario. Podemos realizar distintas acciones con esos datos como, por ejemplo, validarlos.

Agrupar campos con fieldset

La etiqueta <fieldset> agrupa campos que están relacionados dentro de un formulario. Por ejemplo, permite reunir varios botones de radio que responden a una misma pregunta.

Dentro de <fieldset> se usa <legend> para escribir el título o la pregunta del grupo. Esta estructura ayuda a entender el formulario y permite que los lectores de pantalla relacionen los controles correctamente.

Modalidad preferida:

Atributos del formulario

  • for conecta un <label> con un campo por su id.
  • name da nombre al dato que se enviaría.
  • type define el tipo de input.
  • placeholder muestra una pista dentro del campo.
  • value define un valor inicial o el valor de una opción.
  • Los botones de radio forman un grupo cuando comparten el mismo name.
  • checked marca la opción seleccionada inicialmente.

10. HTML semántico

HTML semántico significa elegir etiquetas por su significado, no por cómo se ven. Esto ayuda a lectores de pantalla, buscadores y otras personas que leen el código.

Etiquetas semánticas usadas en esta página

  • <header>: encabezado de una página o sección.
  • <nav>: navegación o menú de enlaces.
  • <main>: contenido principal.
  • <section>: bloque temático.
  • <article>: contenido que puede entenderse por sí mismo.
  • <aside>: información complementaria.
  • <footer>: cierre de una página o sección.

Nota para recordar

Si una etiqueta describe bien el propósito del contenido, probablemente es una buena elección.

En este bloque aprenderás a seleccionar elementos HTML y modificar su presentación visual.

11. Qué es CSS y cómo se conecta con HTML

CSS significa Cascading Style Sheets, o «Hojas de Estilo en Cascada». Es un lenguaje de estilos que permite describir cómo se muestran los elementos HTML en el navegador.

Con HTML organizamos el contenido. Con CSS podemos cambiar su apariencia, por ejemplo, sus colores, tamaños de texto, fuentes y espacios.

Conectar HTML con CSS

Esta página ya contiene la siguiente etiqueta dentro de <head>: 

<link rel="stylesheet" href="styles.css">
<link>
Conecta el documento HTML con otro recurso.
rel="stylesheet"
Indica que el recurso conectado es una hoja de estilos.
href="styles.css"
Indica la ubicación del archivo CSS que debe leer el navegador.

Idea importante

El archivo HTML conserva el contenido y su estructura. El archivo CSS contiene las reglas que modifican cómo se presenta ese contenido.

12. Selector, propiedad y valor

Una regla CSS tiene un selector y un bloque de declaraciones escrito entre llaves.

                  h1 {
                            color: red;
                            font-size: 32px;
                        }
h1: selector
Busca los elementos HTML a los que se aplicará la regla.
color y font-size: propiedades
Indican qué características visuales queremos modificar.
red y 32px: valores
Indican el nuevo valor que tendrá cada propiedad.

Signos que debemos recordar

  • Las llaves { } contienen las declaraciones de la regla.
  • Los dos puntos : separan una propiedad de su valor.
  • El punto y coma ; termina cada declaración.

Un mismo selector puede contener varias declaraciones. Cada una se escribe en su propia línea para que el código resulte más fácil de leer.

13. Selectores de etiqueta

Un selector de etiqueta, también llamado selector de elemento o de tag, busca todos los elementos que tengan ese nombre de etiqueta. 

p {
    color: darkblue;
}

La regla anterior haría coincidir todos los elementos <p> de la página. No necesitamos agregar ningún atributo al HTML para utilizar este selector.

En styles.css también usamos los selectores body y code. Cada uno encuentra todas las etiquetas de su tipo.

14. Selectores por id y clase

Selector por id

El atributo id identifica un elemento único dentro de la página. En CSS escribimos el símbolo # antes de su valor. 

#inicio {
    background-color: #cfe8f3;
    padding: 30px;
}

Esta regla encuentra solamente el elemento que tiene id="inicio". No se escribe la palabra id dentro del selector.

Selector por clase

Una clase puede utilizarse en varios elementos. En CSS escribimos un punto . inmediatamente antes del nombre de la clase. 

.paso {
    background-color: white;
    padding: 16px;
    margin-left: 20px;
}

Todas las secciones de esta guía tienen class="paso", por lo que la misma regla puede modificar varias secciones al mismo tiempo. Un elemento también puede tener varias clases separadas por espacios.

15. Selectores de atributo

Un selector de atributo busca elementos según los atributos escritos en su etiqueta de apertura. Los corchetes [ ] forman parte del selector.

Presencia y valor exacto

[checked] {
    margin-left: 40px;
}

input[type="radio"] {
    accent-color: #243447;
}
  • [checked] encuentra cualquier elemento que tenga el atributo.
  • input[type="radio"] encuentra los <input> cuyo valor sea exactamente radio.
  • a[target="_blank"] encuentra enlaces que se abren en otra pestaña.

Buscar patrones dentro del valor

Para practicar atributos personalizados válidos en HTML usamos nombres que comienzan con data-. Cada párrafo siguiente permite observar un patrón diferente:

[data-estado] busca la presencia y [data-estado="activo"] busca el valor exacto.

[data-tema*="css"] busca el texto css en cualquier posición.

[data-etapa^="intro"] busca valores que comienzan con intro.

[data-archivo$=".pdf"] busca valores que terminan con .pdf.

[data-tecnologias~="css"] busca la palabra completa css dentro de una lista de palabras separadas por espacios.

El operador *= busca una parte del texto; ^=, su comienzo; $=, su final; y ~=, una palabra completa dentro de una lista.

16. Agrupación de selectores y errores

Cuando varios selectores necesitan las mismas declaraciones, podemos separarlos con comas y escribir un solo bloque. 

h1,
h2,
h3,
h4,
h5,
h6 {
    color: #3f3c8f;
}

Este grupo encuentra todos los niveles de título indicados. Es equivalente a escribir seis bloques con las mismas declaraciones, pero evita repetir código.

¿Qué ocurre si un selector tiene un error?

p,
##selector-invalido {
    color: red;
    font-size: 16px;
    padding: 10px;
}

##selector-invalido no es un selector válido. Como se encuentra dentro de un grupo, el navegador descarta la regla completa y tampoco aplica esas declaraciones a los párrafos.

El ejemplo está comentado en styles.css para que no rompa el resultado final. Durante la clase se puede activar temporalmente, observar qué ocurre y volver a comentarlo.

18. Pseudo-clases y pseudo-elementos

Los pseudo-selectores permiten seleccionar un elemento con más precisión sin agregar otro atributo al HTML. Se escriben después del selector principal.

:hover
Pseudo-clase: selecciona un elemento mientras el puntero está sobre él.
::first-letter
Pseudo-elemento: selecciona la primera letra del contenido.

Una pseudo-clase usa un solo signo de dos puntos y describe un estado, una condición o una posición. Un pseudo-elemento usa dos signos y selecciona una parte concreta del elemento.

19. Interacción con pseudo-clases

:hover se activa mientras el puntero está sobre un elemento. :focus se activa cuando un control recibe el foco mediante un clic o el teclado.

Pasa el puntero sobre este enlace 

.enlace-interactivo:hover {
    background-color: #dff3e5;
    color: #0b5d2a;
}

.campo-enfoque:focus {
    border-color: #4d478f;
    outline: 3px solid #dcd8f4;
    outline-offset: 2px;
}

Qué observar: el enlace cambia mientras el puntero está encima y el campo muestra un contorno al recibir el foco.

20. Estados de formularios

Algunas pseudo-clases describen el estado actual de un control. :disabled encuentra controles deshabilitados, :not(:disabled) excluye esos controles y :checked encuentra opciones marcadas.

Compara los campos Nombre y Apellido de la sección de formularios.

Ir al formulario de ejemplo.

input.campo-estado:disabled {
    background-color: #e3e7eb;
    color: #5f6b76;
    cursor: not-allowed;
}

input.campo-estado:not(:disabled) {
    background-color: #f6fbfe;
    border: 2px solid #2f6f95;
}

.control-marcable:checked {
    accent-color: #4d478f;
}

Qué observar: Nombre conserva un borde azul, Apellido aparece deshabilitado y la casilla marcada usa el color violeta.

21. Posición dentro de una lista

También podemos seleccionar elementos según su posición entre los hijos de un mismo padre. La posición comienza en 1.

  1. Primer elemento.
  2. Segundo elemento.
  3. Tercer elemento.
  4. Último elemento.
.lista-posiciones li:first-child {
    background-color: #e5f6df;
}

.lista-posiciones li:last-child {
    border-bottom: 3px solid #5a54a4;
}

.lista-posiciones li:nth-child(even) {
    color: #4d478f;
    font-weight: bold;
}

Qué observar: el primero tiene fondo verde claro, el último tiene un borde inferior y las posiciones pares usan texto violeta.

22. Excluir elementos con :not()

:not() selecciona los elementos que no coinciden con el selector escrito entre paréntesis. En este ejemplo excluimos la tarea que ya tiene la clase completada.

  • Leer la explicación.
  • Probar el ejemplo.
  • Resolver el ejercicio.
.lista-tareas li:not(.completada) {
    border-left: 4px solid #b45309;
    padding-left: 8px;
}

Qué observar: solamente las dos tareas sin la clase completada reciben el borde naranja.

23. Partes de un elemento

Los pseudo-elementos seleccionan una parte que no aparece como una etiqueta separada en el HTML. Cada ejemplo siguiente trabaja con una parte diferente.

Esta primera letra recibe un estilo especial.

  • HTML organiza.
  • CSS presenta.
.parrafo-inicial::first-letter {
    color: #a61b1b;
    font-size: 2em;
    font-weight: bold;
}

.campo-placeholder::placeholder {
    color: #626c78;
    font-style: italic;
}

.lista-marcadores li::marker {
    color: #5a54a4;
    font-weight: bold;
}

Qué observar: cambia la primera letra del párrafo, la pista del campo y los marcadores de la lista, pero no todo el elemento.

24. Contenido con ::before y ::after

::before y ::after pueden generar contenido antes o después del contenido original. Para que aparezcan, necesitan la propiedad content.

Título decorado desde CSS

.titulo-decorado::before {
    color: #9a4b00;
    content: "★ ";
}

.titulo-decorado::after {
    color: #176b36;
    content: " ✓";
}

Qué observar: la estrella y la marca aparecen alrededor del título aunque esos símbolos no están escritos dentro del <h3>.

El contenido generado en este ejemplo es decorativo; la información importante debe permanecer en el HTML.

25. Práctica de pseudo-selectores

Resuelve cada desafío modificando temporalmente una de las reglas anteriores. Después de observar el resultado, vuelve a dejar la regla original.

  1. Cambiar el color del enlace solo durante :hover.
  2. Seleccionar únicamente los elementos impares con :nth-child(odd).
  3. Agregar un símbolo decorativo mediante ::before y content.

En cada ejercicio identifica primero el elemento HTML, luego el estado o la parte que deseas seleccionar y finalmente el cambio visual que esperas observar.

26. Especificidad y prioridad

Cuando varias reglas coinciden con el mismo elemento, la especificidad ayuda al navegador a decidir cuál tiene prioridad. Podemos representarla con cuatro grupos de números.

1-0-0-0: estilo inline
Se escribe en el atributo style del propio elemento.
0-1-0-0: selector por ID
Ejemplo: #texto-especificidad.
0-0-1-0: clase, pseudo-clase o atributo
Ejemplos: .ejemplo-especificidad, :hover y [data-prioridad].
0-0-0-1: elemento o pseudo-elemento
Ejemplos: samp y ::before.

Ejemplo real

El siguiente elemento coincide con reglas de elemento, atributo, clase e ID. Además tiene un estilo inline, por lo que el texto queda rojo.

Este texto recibe varias reglas al mismo tiempo. 

<samp id="texto-especificidad"
    class="ejemplo-especificidad"
    data-prioridad="atributo"
    style="color: #a61b1b;">
    Este texto recibe varias reglas al mismo tiempo.
</samp>
samp {
    color: #176b36;
}

[data-prioridad="atributo"] {
    color: #9a4b00;
}

.ejemplo-especificidad {
    color: #6b3fa0;
}

#texto-especificidad {
    color: #245775;
}

.ejemplo-especificidad:hover {
    background-color: #fff1b8;
}

samp::before {
    content: "Muestra: ";
    font-weight: bold;
}

Qué observar: el texto permanece rojo por el estilo inline, aparece el prefijo creado con ::before y el fondo cambia al pasar el puntero.

Empate de especificidad

Este párrafo tiene dos clases con la misma especificidad. 

.empate-primero {
    background-color: #d7efff;
}

.empate-segundo {
    background-color: #e5f6df;
}

Ambas reglas tienen 0-0-1-0. Como .empate-segundo aparece después en styles.css, su fondo verde claro gana. Cada selector adicional suma en su nivel.

El estilo inline es útil para observar la prioridad, pero normalmente conviene conservar los estilos generales en la hoja CSS para evitar repeticiones.

27. Elementos inline y block

Un elemento block comienza en una línea nueva y ocupa el ancho disponible. Un elemento inline permanece dentro de la línea y ocupa el espacio de su contenido.

Texto anterior span inline texto posterior en la misma línea.

Segundo div block
.ejemplo-inline {
    background-color: #fff1b8;
    border: 2px solid #9a4b00;
    display: inline;
    padding: 4px;
}

.ejemplo-block {

28. Modelo de caja y box-sizing

Todo elemento visible se representa como una caja formada por contenido, padding, border y margin. La propiedad box-sizing define cómo se interpreta el ancho declarado.

  • Área amarilla: espacio exterior donde se observa el margin.
  • Línea azul oscura: border de 6px.
  • Área celeste: padding de 16px.
  • Área blanca: content.

Las demostraciones aparecen una debajo de la otra porque cada tarjeta conserva el flujo normal de un elemento block. Cada zona amarilla tiene el ancho exacto de la caja más sus márgenes laterales, para que los 10px se observen a ambos lados.

content-box (valor inicial)

margin: 10px por lado

width: 150px

border-box

margin: 10px por lado

content
106px disponibles

Caja visible: 150px. El content recibe 150 - 32 de padding - 12 de border = 106px. Con ambos márgenes ocupa 170px.

29. Introducción a Flexbox

Flexbox es un sistema de CSS para distribuir elementos dentro de un contenedor. Primero elegimos el elemento padre y le aplicamos display: flex. Sus hijos directos se convierten en flex items o elementos flexibles.

Usaremos el mismo HTML en las dos demostraciones. La única diferencia será el valor de display aplicado al contenedor.

HTML objetivo

                      <div class="flex-demo flex-demo-activo">
                                <div class="flex-item">Caja 1</div>
                                <div class="flex-item">Caja 2</div>
                                <div class="flex-item">Caja 3</div>
                                <div class="flex-item">Caja 4</div>
                            </div>

Después: contenedor flex

.flex-demo-activo {

Qué observar: en el flujo normal cada div empieza en una línea nueva. Al aplicar display: flex al padre, sus hijos directos se ubican en una fila. Los elementos que están fuera del contenedor no se convierten en flex items.
