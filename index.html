Que es html

Html es un lenguaje de marcado que nos permite escribir un texto el cual el navegador intepreta y nos muestra en pantalla

Html no se usa para decorar la informacion, solo para estructurarla, y tampoco es programable, eso lo hacemos con javascript Este lenguaje lo usaremos para organizar textos, mostrar enlaces, mostrar imagenes, tablas, formularios, etc.

Idea importante

Una etiqueta describe una parte del contenido. por ejemplo <p> representa un parrafo y <h1> representa el titulo principal de la pagina

Imagenes

La etiqueta <img> muestra una imagen. Normalmente se usa src para indicar la ruta de la imagen y alt para describirla.

Tablas

Las tablas sirve para mostrar informacion o datos organizados en filas y columnas, es decir, tabulados.
